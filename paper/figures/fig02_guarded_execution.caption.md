English caption:
Production execution guards and bounded backend fallback. After snapshotting, normalization, and parsing, each selected backend must provide legal routed geometry and forward clock phases. The candidate is checked against the original scalar Verilog by exhaustive Boolean evaluation for 1--11 inputs, then mapped to verify nonempty QCA output and matching declared I/O terminal counts. The amber error arrow summarizes the exception handler around one candidate; it is not an additional circuit path. In auto mode, failures are retained and the next available backend is attempted within the remaining shared budget; the first accepted candidate ends selection. An explicitly selected backend stops on rejection. Exhaustion leaves the job failed and blocks downstream execution. Persisted state supports hash verification and continuation of unfinished stages; saved P&R and device-interface evidence is rechecked on resume. Circuits above the Boolean-check limit are explicitly marked not performed, so acceptance outside that limit does not assert source/DAG equivalence. Neither the Boolean check nor terminal counts prove device waveform correctness or clock-latency alignment.
